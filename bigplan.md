# Portfolio Website — Big Plan

## Goal
Build a clean, dark-themed, static, SEO/crawler-friendly single-page portfolio for **Robert** (Senior Technical Lead).

- Source code lives in `tj-portfolio/` (Vite + React + TypeScript)
- `npm run build` outputs `index.html` + `assets/` directly to the **repo root**
- GitHub Pages serves the root `index.html` at `RobertJif.github.io`

---

## Decisions

| Topic | Decision |
|---|---|
| Display name | Robert |
| Hero subtitle | Senior Technical Lead |
| Theme | Dark, no animations |
| Sections | Hero ? About ? Experience ? Skills ? Projects ? Contact |
| Contact links | LinkedIn, GitHub, Email |
| CV download | Yes — `downloads/Robert_CV.pdf` |
| Experience shown | Last 3 roles + total years of experience in hero |
| Skills layout | Grouped tag cloud |
| Projects layout | Timeline linked to employment, JSON-config driven |
| Build output | Vite dist ? repo root (`../` from `tj-portfolio/`) |

---

## Steps

### Step 1 — Portfolio Data Config
**File:** `tj-portfolio/src/data/portfolio.json`

Single source-of-truth JSON for all content.

### Step 2 — Vite Build Config
**File:** `tj-portfolio/vite.config.ts`

Set `build.outDir: '../'` and `build.emptyOutDir: false`.

### Step 3 — Root HTML Meta
**File:** `tj-portfolio/index.html`

SEO meta, Open Graph tags.

### Step 4 — CSS Design System
**Files:** `tj-portfolio/src/index.css`, `tj-portfolio/src/App.css`

Dark theme CSS variables. No frameworks.

### Step 5 — Nav Component
**File:** `tj-portfolio/src/components/Nav.tsx`

### Step 6 — Hero Component
**File:** `tj-portfolio/src/components/Hero.tsx`

### Step 7 — About Component
**File:** `tj-portfolio/src/components/About.tsx`

### Step 8 — Experience Component
**File:** `tj-portfolio/src/components/Experience.tsx`

### Step 9 — Skills Component
**File:** `tj-portfolio/src/components/Skills.tsx`

### Step 10 — Projects Component
**File:** `tj-portfolio/src/components/Projects.tsx`

### Step 11 — Contact Component
**File:** `tj-portfolio/src/components/Contact.tsx`

### Step 12 — App.tsx Wiring
**File:** `tj-portfolio/src/App.tsx`

### Step 13 — Build and Verify
Run `npm run build`, confirm output at repo root.
